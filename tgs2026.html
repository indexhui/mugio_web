01 / GAME OVERVIEW

一段關於日常、理解與散落回憶的療癒冒險。

《走走小日》是一款以生活日常為舞台的療癒系點擊冒險遊戲。玩家跟著上班族小麥穿梭城市，尋找散落各處的小日獸，拼回交換日記，也找回兩名室友曾錯過的理解。

ABOUT THE GAME / 作品介紹

主角小麥發現室友小白陷入神祕沉睡，兩人的交換日記失去文字，日記中的「小日獸」也散落城市。玩家從日記拼圖找出線索、安排每日探索路線，在捷運站、便利商店與辦公室觀察互動、完成輕量小遊戲並拍下小日獸，逐步修復回憶與兩人的理解。

核心魅力

用短篇幅、可親近的日常事件，串起路線安排、場景觀察、角色收集與情感敘事。

02 / PARTNERSHIP

我們正在尋找，能一起把《走走小日》帶得更遠的夥伴。

麥尾擁有原創世界觀、視覺、敘事與互動設計能力，現階段希望認識具備開發、發行與市場經驗的團隊。無論是補足製作能力、進入日本與海外市場，或探索適合作品的合作形式，我們都期待從一場具體的交流開始。
