02 / GAME

Moments / てくてく日和

在熟悉的通勤路上，發現藏在生活角落的奇遇。

《走走小日》是一款以生活日常為舞台的療癒系點擊冒險遊戲。玩家跟著上班族小麥穿梭城市，尋找散落各處的小日獸，拼回交換日記，也找回兩名室友曾錯過的理解。

ABOUT THE GAME / 作品介紹

主角是上班族小麥發現室友小白陷入沉睡，兩人的交換日記失去文字與回憶，原本存在於日記中的「小日獸」也散落城市各處。玩家需從日記拼圖中找出線索，將捷運站、便利商店與早餐店等地點排入每日行程，規劃探索路線；途中透過觀察、點擊互動、情境選擇與輕量小遊戲完成挑戰，拍照收集小日獸。每次收集都會解鎖殘缺日記與角色回憶，讓小麥逐步理解室友，也重新看見自己在相似情境下的選擇與習慣。

遊戲類型

STORY / 故事

一次爭執後，兩人的日常停在了那個早晨。

一次爭執後，小麥帶著怒氣出門。回家時，她卻發現室友小白仍維持著早晨的姿勢，房內紙張停在半空，兩人的交換日記也失去文字。在小貝狗的引導下，她得知日記裡的小日獸已散落城市各處。

你將循著線索，在捷運站、便利商店、早餐店與辦公室之間尋找牠們，拼回被遺忘的生活片段。每次收集，都讓小麥更了解小白對於生活的想法。

ORIGIN / 源起

從通勤、工作與共同生活裡，看見關係中的細微差異。

《走走小日》源自團隊對通勤、工作與共同生活的觀察。麥尾由具有插畫、產品設計、程式開發與文字創作背景的成員組成。我們希望把那些看似微小、卻會影響關係的習慣與摩擦，轉化成玩家可以觀察與參與的事件，在熟悉的生活場景中，重新看見人與人之間的差異。

HOW IT PLAYS / 遊玩流程
01

安排每日路線

依照日記線索，把捷運站、早餐店與街角排入行程。

02

觀察與選擇

點擊場景、回應情境，在微小選擇裡看見自己。

03

拍下小日獸

用相機捕捉那些映照城市習慣的不可思議生物。

04

拼回交換日記

解鎖殘缺文字與角色回憶，讓故事逐步復原。
